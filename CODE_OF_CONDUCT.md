# Code of Conduct

## Our commitment

We are committed to providing a welcoming, safe, and constructive community for everyone, regardless of experience, identity, background, or ability.

## Expected behavior

- Be respectful and assume good intent.
- Give technical feedback about the work, not the person.
- Welcome questions and help contributors learn.
- Acknowledge mistakes and correct them.
- Protect private information shared during security or moderation reports.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, personal attacks, doxxing, and sustained disruption are not permitted in project spaces.

## Enforcement

Project maintainers may edit or remove content and temporarily or permanently restrict participation when necessary to protect the community. Report conduct concerns privately to the repository owner through their GitHub profile contact options. Reports will be reviewed fairly and kept confidential when possible.

## Scope

This code applies in repository spaces and when someone is publicly representing the project.
