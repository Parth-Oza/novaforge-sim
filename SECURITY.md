# Security Policy

## Supported versions

NovaForge Sim is pre-1.0 software. Security fixes are applied to the latest release on the default branch.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature on this repository. Include reproduction steps, affected versions, impact, and any suggested mitigation.

You should receive an acknowledgment within seven days. Please allow maintainers reasonable time to investigate and publish a fix before public disclosure.

## Safety boundary

NovaForge Sim is a research and development tool. Simulation results are not evidence that a physical robot is safe. Users remain responsible for hardware safeguards, independent validation, and compliance with applicable requirements.
